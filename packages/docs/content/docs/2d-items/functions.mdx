## What is a Function2D?

A `Function2D` plots the graph of a single-variable function $y = f(x)$. You give it a plain JavaScript function and it samples and draws the curve. Unlike a [parametric curve](/docs/2d-items/parametric), a function graph has exactly one $y$ for each $x$, which lets it sample efficiently across whatever range is on screen.

<Functions2DDemo />

A `function2d` graph of $\sin(x)$ on an `"infinite"` domain, so it re-samples to fill the board as you pan and zoom. Dragging the `point2d` handle along the x-axis evaluates `f` there, and the `overlay2d` reads off the result.

## Basic Usage

```typescript
scene.create("function2d", {
  f: (x) => 0.25 * x * x - 1,
  color: "dodgerblue",
  thickness: 2,
});
```

## Domain

The `domain` property decides which $x$ values are drawn:

- **`"infinite"`**: the graph is sampled across the visible viewport and re-sampled as you pan or zoom, so it always fills the screen.
- **`[min, max]`**: the graph is drawn only over that fixed interval.

```typescript
// Always fills the visible width
scene.create("function2d", {
  f: (x) => Math.sin(x),
  domain: "infinite",
});

// Drawn only from x = 0 to x = 6
scene.create("function2d", {
  f: (x) => Math.sin(x),
  domain: [0, 6],
});
```

## Discontinuities

Jumps and vertical asymptotes are handled automatically: the curve splits into separate branches instead of being joined by a vertical segment, so functions like `tan(x)` or `1/x` render correctly out of the box. The curve also breaks wherever `f(x)` returns a non-finite value (`NaN` or `Infinity`), so a function like `(x) => Math.log(x)` simply has no curve where it is undefined.

If you know exactly where a function breaks, you can still list those $x$ values in `discontinuities` to split the curve at precisely those points:

```typescript
scene.create("function2d", {
  f: (x) => 1 / (x - 2),
  discontinuities: [2],
});
```

## Endpoint Markers

Where a curve stops, you can mark whether the value is attained or excluded, in the usual textbook notation: `"closed"` is a filled dot, `"open"` is a hollow ring.

A `discontinuities` entry can be an object with a marker style per side:

```typescript
// Jump: the left branch ends open at (1, 2), the right starts closed at (1, 1).
scene.create("function2d", {
  f: (x) => (x < 1 ? x + 1 : x * x),
  discontinuities: [{ x: 1, left: "open", right: "closed" }],
});

// Hole at (1, 2): both sides open.
scene.create("function2d", {
  f: (x) => (x * x - 1) / (x - 1),
  discontinuities: [{ x: 1, left: "open", right: "open" }],
});
```

The ends of a finite domain take markers through `endpoints`, where `start` is the lower-$x$ end:

```typescript
scene.create("function2d", {
  f: (x) => Math.sqrt(x),
  domain: [0, 9],
  endpoints: { start: "closed", end: "open" },
});
```

`markerRadius` sets the marker size in CSS pixels.

## Sampling

Sampling is automatic: the library decides how densely to evaluate `f` from the shape of the curve and the current zoom, so steep slopes, tight oscillations, and asymptotes render smoothly without any configuration. The only sampling control is the `discontinuities` list above.

## Styling

```typescript
scene.create("function2d", {
  f: (x) => Math.cos(x),
  color: "tomato",
  thickness: 3,
});
```

## Examples

### Reactive Function

Drive the function from an atom to reshape the graph live:

```typescript
const k = scene.atom(1);

scene.create("function2d", {
  f: scene.atom((get) => {
    const a = get(k);
    return (x: number) => a * x * x;
  }),
  domain: "infinite",
  color: "dodgerblue",
});

// Change the parabola's width
k.set(0.5);
```

### Highlighting the Area Under a Curve

To shade the region between a function and an axis, pair it with the [functionArea2D](/docs/constructions/function-area-2d) construction, which samples the same function and fills the area as a [region](/docs/2d-items/regions).

## Updating Properties

```typescript
const graph = scene.create("function2d", {
  f: (x) => x * x,
  color: "white",
});

graph.f.set((x) => Math.sin(x));
graph.domain.set([-3, 3]);
graph.color.set("gold");
graph.thickness.set(3);
```

## API Reference

### Options

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `f` | `(x: number) => number` | `(x) => x` | The function to plot |
| `domain` | `"infinite" \| [number, number]` | `[-10, 10]` | Range of $x$ to draw, or `"infinite"` to follow the viewport |
| `discontinuities` | `Function2DDiscontinuity[]` | `[]` | $x$ values where the curve should break, as bare numbers or `{ x, left?, right? }` objects with endpoint marker styles per side |
| `endpoints` | `{ start?: EndpointStyle; end?: EndpointStyle }` | `{}` | Markers at the ends of a finite domain; `start` is the lower-$x$ end |
| `markerRadius` | `number` | `4` | Endpoint marker radius in CSS pixels |
| `color` | `string` | `"white"` | CSS color string |
| `thickness` | `number` | `1` | Line width |
| `opacity` | `number` | `1` | Opacity (0 to 1) |
| `visible` | `boolean` | `true` | Whether the graph is shown |
| `pointerEvents` | `"auto" \| "none"` | `"auto"` | Whether the graph receives pointer events |
| `tags` | `string[]` | `[]` | Custom tags |

### Returned Item

| Field | Type | Description |
|-------|------|-------------|
| `id` | `string` | Unique identifier |
| `f` | `BoundAtom<(x: number) => number>` | Function atom |
| `domain` | `BoundAtom<"infinite" \| [number, number]>` | Domain atom |
| `discontinuities` | `BoundAtom<Function2DDiscontinuity[]>` | Discontinuities atom |
| `endpoints` | `BoundAtom<{ start?: EndpointStyle; end?: EndpointStyle }>` | Domain endpoint markers atom |
| `markerRadius` | `BoundAtom<number>` | Marker radius atom |
| `color` | `BoundAtom<string>` | Color atom |
| `thickness` | `BoundAtom<number>` | Thickness atom |
| `opacity` | `BoundAtom<number>` | Opacity atom |
| `visible` | `BoundAtom<boolean>` | Visibility atom |
| `pointerEvents` | `BoundAtom<string>` | Pointer events atom |
| `tags` | `BoundAtom<string[]>` | Tags atom |
