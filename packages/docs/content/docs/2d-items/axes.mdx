## What is Axes2D?

`Axes2D` renders X and Y coordinate axes, with optional arrowheads, tick marks, and numeric labels. It provides orientation and scale reference for a plane visualization. The axes cross at the world origin by default, and the `origin` option moves that crossing point anywhere.

## Basic Usage

```typescript
scene.create("axes2d", {
  x: true,
  y: true,
});
```

## Axis Configuration

Each axis takes one of three values:

- **`true`**: draw the axis across the visible viewport. It re-extends as you pan or zoom, so it always spans the screen.
- **`false`**: hide this axis.
- **`[min, max]`**: draw the axis over a fixed range.

```typescript
// Both axes span the viewport
scene.create("axes2d", { x: true, y: true });

// X spans the viewport, Y is fixed from 0 to 8
scene.create("axes2d", {
  x: true,
  y: [0, 8],
});

// Only the x-axis
scene.create("axes2d", {
  x: true,
  y: false,
});
```

## Styling

### Color and Thickness

```typescript
scene.create("axes2d", {
  x: true,
  y: true,
  color: "#888",
  thickness: 2,
});
```

### Arrows

`arrows` picks which ends of the axes carry an arrowhead: `"none"`, `"start"` (the range's min side), `"end"` (the max side), or `"both"` (the default). One value applies to both enabled axes. `headLength` and `headWidth` size the heads in CSS pixels, like vector2d's fields of the same names, and `tickLength` sizes the tick marks.

A tick that lands exactly on a range end carrying an arrowhead is dropped, label included: the head visually replaces it.

```typescript
scene.create("axes2d", {
  x: true,
  y: true,
  arrows: "none",
});

// A time axis: arrowhead only in the forward direction
scene.create("axes2d", {
  x: [0, 10],
  y: false,
  arrows: "end",
});
```

## Origin

`origin` sets the world point where the two axes cross, `(0, 0)` by default. Axis lines, tick marks, and arrowheads shift with it, while tick values and labels stay absolute world coordinates. The tick under the crossing point is skipped, so it never collides with the crossing axis line.

```typescript
// Axes crossing at (2, 1)
scene.create("axes2d", {
  x: true,
  y: true,
  origin: vec2(2, 1),
});
```

For a number line with its own value scale, independent of world coordinates, see [Number Line](/docs/2d-items/number-line).

## Tick Marks and Labels

Enable `tickmarks` to draw ticks at regular intervals, and `labels` to print the numeric value at each tick:

```typescript
scene.create("axes2d", {
  x: true,
  y: true,
  tickmarks: true,
  labels: true,
});
```

### Tick Spacing

`tickStep` sets the interval between ticks. Pass a number for a fixed step, or `"auto"` to pick a round step that adapts to the zoom level:

```typescript
// A tick every 2 units
scene.create("axes2d", {
  x: true,
  y: true,
  tickmarks: true,
  tickStep: 2,
});

// Step chosen automatically from the current zoom
scene.create("axes2d", {
  x: true,
  y: true,
  tickmarks: true,
  labels: true,
  tickStep: "auto",
});
```

### Styling Labels

Tick labels carry a default look (color, font, and a subtle text-shadow for legibility). Providing `labelClassName` or `labelStyle` replaces that default styling entirely, so you can theme labels without fighting inline styles:

```typescript
scene.create("axes2d", {
  x: true,
  y: true,
  labels: true,
  labelClassName: "axis-label",
});

scene.create("axes2d", {
  x: true,
  y: true,
  labels: true,
  labelStyle: "color: #aaa; font-size: 11px;",
});
```

## Examples

Axis ranges can be reactive:

```typescript
const scale = scene.atom(5);

scene.create("axes2d", {
  x: scene.atom((get) => [-get(scale), get(scale)]),
  y: scene.atom((get) => [-get(scale), get(scale)]),
});

scale.set(10);
```

## API Reference

### Options

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `x` | `boolean \| [number, number]` | `true` | X-axis configuration |
| `y` | `boolean \| [number, number]` | `true` | Y-axis configuration |
| `origin` | `Vec2` | `vec2(0, 0)` | World point where the axes cross |
| `color` | `string` | `"white"` | Axis color |
| `thickness` | `number` | `1` | Line width |
| `arrows` | `"none" \| "start" \| "end" \| "both"` | `"both"` | Which axis ends carry an arrowhead |
| `tickmarks` | `boolean` | `false` | Show tick marks |
| `tickStep` | `number \| "auto"` | `1` | Interval between ticks, or `"auto"` to adapt to zoom |
| `tickLength` | `number` | `12` | Full tick length, CSS pixels |
| `headLength` | `number` | `14` | Arrowhead length, CSS pixels |
| `headWidth` | `number` | `10` | Arrowhead base width, CSS pixels |
| `labels` | `boolean` | `false` | Show numeric labels at ticks |
| `labelClassName` | `string` | `""` | CSS class for tick labels (replaces default label styling) |
| `labelStyle` | `string` | `""` | Inline CSS for tick labels (replaces default label styling) |
| `visible` | `boolean` | `true` | Whether the axes are shown |
| `pointerEvents` | `"auto" \| "none"` | `"none"` | Whether the axes receive pointer events |
| `tags` | `string[]` | `[]` | Custom tags |

### Axis Configuration Values

| Value | Meaning |
|-------|---------|
| `true` | Draw the axis across the visible viewport |
| `false` | Hide the axis |
| `[min, max]` | Draw the axis over a fixed range |

| Field | Type | Description |

| `arrows` | `BoundAtom<ArrowEnds>` | Arrows atom |
| `tickmarks` | `BoundAtom<boolean>` | Tick marks atom |
| `tickStep` | `BoundAtom<number \| "auto">` | Tick step atom |
| `tickLength` | `BoundAtom<number>` | Tick length atom |
| `headLength` | `BoundAtom<number>` | Head length atom |
| `headWidth` | `BoundAtom<number>` | Head width atom |
| `labels` | `BoundAtom<boolean>` | Labels atom |
| `labelClassName` | `BoundAtom<string>` | Label class atom |
| `labelStyle` | `BoundAtom<string>` | Label style atom |
| `visible` | `BoundAtom<boolean>` | Visibility atom |
| `pointerEvents` | `BoundAtom<string>` | Pointer events atom |
| `tags` | `BoundAtom<string[]>` | Tags atom |
